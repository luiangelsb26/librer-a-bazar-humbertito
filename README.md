# Humbertito IA

Sistema de gestión comercial para una librería bazar, desarrollado con Streamlit y SQLite.

## Ejecutar el proyecto

1. Crear y activar un entorno virtual.
2. Instalar las dependencias:

   ```powershell
   pip install -r requirements.txt
   ```

3. Crear la base de datos local:

   ```powershell
   python database.py
   ```

4. Iniciar la aplicación:

   ```powershell
   streamlit run app.py
   ```

La base de datos local se guarda en `data/humbertito.db` y no se sube al repositorio.
